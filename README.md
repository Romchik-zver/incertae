# incertae

Нерешённые проблемы, загадки и вопросы человечества. Сортировано по областям знаний.

## Стек

- **Remix v3** (React Router v7 + Vite)
- **Tailwind CSS v4**
- **TypeScript**
- **Lucide React** (иконки)

## Установка

```bash
npm install
```

## Разработка

```bash
npm run dev
```

Откроется на `http://localhost:5173`

## Сборка

```bash
npm run build
npm start
```
